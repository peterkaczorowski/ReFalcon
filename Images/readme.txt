This folder contains pictures of rev.1 PCB assembly. It is a good reference when assembling rev 1.1 because both revisions contains same components in the same locations.

Pic.1&2 Recommend to ise IC sockets for all DIP and PLCC chips.

Pic.3&4 You can use socketing for crystals and oscillators.

Pic.5 Area around the fan bracket. 

Pic.6 PAL/GAL chips socketing. Don't forget to Install jumper at W1

Pic.7 Standard configuration jumpers. Refer to Atari Falcon 030 Field Service Guide for details or simply jump as shown.

Pic.8 Newly added in replica jumpers JP1 through JP8. Follow Rev 1.1 bill of materials in this repository to identify jumpers to be shorted and those to be left open.

Notes of exceptions:
1. Ignore C6 and C67 capacitor polarity mark printed on the silkscreen on rev.1 photos. Follow the rev 1.1 silk screen polarity mark for these capacitors instead.
